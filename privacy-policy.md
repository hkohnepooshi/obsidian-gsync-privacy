# Privacy Policy – Obsidian GSync

**Last updated: November 2, 2026**

## 1. Introduction

This application uses Google OAuth 2.0 to authorize the Obsidian GSync plugin to synchronize files between my personal Obsidian vault and my Google Drive account.

This application is intended for personal use.

## 2. Information Accessed

The application accesses Google Drive data required by the GSync plugin to synchronize files and folders within the specific Google Drive folder configured by the user.

This may include file contents, file names, folder structures, and file metadata.

## 3. Data Collection and Storage

I do not independently collect, store, or maintain users' Google account information or synchronized files on any external server.

The GSync plugin communicates directly with Google's OAuth services and Google Drive API.

OAuth credentials and refresh tokens are stored locally in the Obsidian plugin configuration on the user's device.

## 4. Data Sharing

I do not sell, rent, or share Google user data with third parties.

Data is transferred directly between the user's device and Google services for authentication and synchronization.

## 5. Data Security

Authentication uses Google OAuth 2.0.

The plugin uses PKCE during the authorization process.

Users should keep their OAuth credentials and refresh tokens confidential and should not share their plugin configuration files.

## 6. Data Retention and Deletion

Synchronized files remain in the user's local Obsidian vault and Google Drive account.

Users can revoke the application's Google account access at any time through their Google Account security settings.

## 7. Changes to This Policy

This Privacy Policy may be updated when necessary. Any changes will be published on this page.

## 8. Contact

For questions about this privacy policy, please contact the application owner through the GitHub repository associated with this application.

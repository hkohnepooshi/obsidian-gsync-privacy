# Obsidian GSync – Personal Google Drive Synchronization

This project provides OAuth authentication for personal use of the Obsidian GSync plugin.

## Purpose

The application allows the user to synchronize a personal Obsidian vault with Google Drive using the Google Drive API.

## Data and Privacy

The application is intended for personal use. Google account data and vault files are accessed only for synchronization purposes.

No independent external server is used to store synchronized files or Google account information.
